```
http://localhost:3000/studio-demo
```

### 启动方式
```bash
# 1. 进入项目目录
cd /home/runner/work/claude-code-marketplace/claude-code-marketplace

# 2. 安装依赖（如果还没安装）
yarn install

# 3. 启动开发服务器
yarn dev

# 4. 访问演示页面
打开浏览器访问: http://localhost:3000/studio-demo
```

### 1. 增强配置页面（Enhanced Config Page）

**页面路径**: `/studio-demo` → 点击 "增强配置页面"

**主要特性：**
- ✅ 10+ 配置项（vs 原来的 2 个）
- ✅ 实时验证（邮箱、URL 格式）
- ✅ 智能提示（每个字段都有帮助文本）
- ✅ 标签管理（动态添加/删除）
- ✅ 简单/高级模式切换
- ✅ 完整的作者、仓库、分类信息
- ✅ 响应式设计

**配置项分组：**

1. **📝 基本信息**
   - 插件名称 *（必填，实时验证格式）
   - 描述 *（必填，多行文本）
   - 版本号 *（必填，遵循 SemVer）

2. **👤 作者信息**
   - 作者姓名 *（必填）
   - 作者邮箱 *（必填，实时验证格式）

3. **🔗 仓库信息**
   - GitHub 仓库 URL（可选，实时验证）

4. **🏷️ 分类和标签**
   - 插件类别 *（下拉选择）
   - 标签（动态添加，显示为标签卡片）

5. **⚙️ 触发配置**（仅高级模式）
   - 触发事件（复选框）
   - 文件过滤器

6. **🎯 运行配置**（仅高级模式）
   - 目标语言
   - 框架

### 2. AI 辅助 Agent 设计器（AI Agent Designer）

**页面路径**: `/studio-demo` → 点击 "AI 辅助设计器"

**主要特性：**
- ✅ 三栏布局（AI 对话 | 规范预览 | 生成结果）
- ✅ 对话式交互（像聊天一样设计 Agent）
- ✅ 实时规范预览
- ✅ 自动代码生成（配置、Prompt、测试用例）
- ✅ 质量评分系统（95/100）
- ✅ 智能建议系统
- ✅ 完整的中英文支持

**设计流程：**

1. **步骤 1：描述需求**
   - AI 提问："这个 Agent 要做什么？"
   - 用户输入：描述 Agent 功能
   - AI 开始构建初始规范

2. **步骤 2：选择检查项**
   - AI 展示复选框列表
   - 用户选择相关检查项（代码风格、最佳实践、安全等）
   - AI 完善规范细节

3. **步骤 3：查看和优化**
   - 左侧：查看完整对话历史
   - 中间：规范预览（实时更新）
   - 右侧：生成的配置、Prompt、测试用例
   - 底部：质量评分和智能建议
